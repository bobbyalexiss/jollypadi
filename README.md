# Jolly Padi® website

A one page React/Vite site for Jolly Padi, a creative marketing studio in Lagos.

## Run locally

```sh
npm install
npm run dev
```

Create a production build with `npm run build` and preview it with `npm run preview`.

## Update the content

- Project, service, Lab, testimonial and lifestyle labels live in `src/content.js`.
- The main page sections and reusable case study component live in `src/main.jsx`.
- Replace `public/assets/lagos-hero.jpg` with the final hero photo or video treatment.
- William’s portrait is in `public/assets/william-duru-alexis.jpg`. The case study and lifestyle image areas remain labeled placeholders until those photos are ready.
- Email, Instagram, TikTok and WhatsApp are connected in `src/main.jsx`.
